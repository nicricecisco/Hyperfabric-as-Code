SWITCHES:
---------
HF6100‑32D
32× QSFP‑DD ports, each supporting 40/100/200/400 GbE speeds and multiple breakout modes 
No native SFP28 or SFP56 ports

HF6100‑60L4D
4× QSFP‑DD ports (used for fabric links, 100 GbE or 400 GbE) -- these are ports 31-34 that are almost always used in fabric connections
60× SFP56 ports supporting 1/10/25/50 GbE speeds 


CABLES:
-------
| Cable Type     | Description                                                                 | Best Use Case                  |
|----------------|-----------------------------------------------------------------------------|--------------------------------|
| **DAC**        | Direct Attach Copper. Passive or active. Very cost-effective, low latency. | Short, intra-rack (≤5m)        |
| **AOC**        | Active Optical Cable. Pre-terminated and plug-and-play.                    | Medium distances (≤30m)        |
| **Transceivers**| Optical modules + fiber (MMF/SMF). Scalable and long-distance capable.     | Long haul (30m–10km and beyond)|

    Factor	Passive DAC	AOC	Transceivers (SMF/MMF)
    Length	≤ 5m	5–30m	≥ 30m (esp. 50m+)
    Power consumption	Very low	Low	Moderate to high
    Cost	Lowest	Mid	Highest
    Port compatibility	QSFP+/QSFP28 etc.	QSFP+/QSFP28/QSFP-DD	Requires optical ports
    Cable thickness/flex	Thick, stiff	Flexible	Thin (fiber)
    Latency	Lowest	Low	Slightly higher
    Hot-swappable ends	No	No	Yes (with transceivers)
    Distance reliability	Drops after 5m	Stable to ~30m	Excellent for 100m–10km+

Type	Medium	Connector	Max Distance (typical)	Active/Passive	Cost	Flexibility
DAC	Copper	QSFP/SFP	~1–5m	Passive	🟢 Cheapest	🟢 High
AOC	Fiber (MMF)	QSFP/SFP	~5–30m	Active	🟡 Moderate	🟢 High
MMF	Fiber	MPO/LC	~70–150m	Passive (via transceivers)	🔴 Higher (due to optics)	🟢 High
SMF	Fiber	MPO/LC	~500m–10km+	Passive (via transceivers)	🔴 Highest	🟡 Moderate


Use QDD‑form cable or module when:
    You need breakout flexibility (e.g. QDD‑2x200G, QDD‑4×100G lanes).
    You want higher lane‑density per physical port for advanced configurations.
Use standard QSFP‑400G‑DR4 when:
    You only need a 4×100G DR4 link, without breakout.
    You’re connecting typical 400G optics between switches without extra lane-level functionality.



LENGTH LOGIC:
-------------
IF length ≤ 5m:
    Use DAC
ELSE IF 5m < length ≤ 30m AND AOC is available:
    Use AOC
ELSE IF 30m < length < 150m:
    Use SMF
ELSE:
    Use MMF



≤3	Mesh	100G DAC or 400G DAC
4–20	Spine-Leaf	100G DAC/AOC depending on rack
21–50	Spine-Leaf	400G DAC/AOC for future-proofing
>50	Spine-Leaf	400G AOC or transceivers (scale)


SPEED LOGIC:
------------
IF speed = 400:
    Use 400G 
ELSE:
    Use 100G

IF speed = 400:
    if length ≤ 3m:
        QDD-400-CU1M  
        QDD-400-CU2M

        QSFP-400G-DR4

        QDD-400G-FR4-S

        "no pluggable supported"

ELSE:
    if length ≤ 3m:
        QSFP-100G-CU1M
        QSFP-100G-CU2M
        QSFP-100G-CU3M
        QSFP-100G-CU5M
    else if length > 3m && length ≤ 30m:

        QSFP-100G-AOC5M

        QSFP-100G-AOC15M
        QSFP-100G-AOC20M
        QSFP-100G-AOC25M
        QSFP-100G-AOC30M
    else if length > 30m && length ≤ 150m:
        QSFP-100G-SR4-S
    else if length > 150m && length ≤ 500m:
        QSFP-100G-DR-S
    else if length > 500m && length ≤ 2000m:
        QSFP-100G-FR-S
    else:
        "no pluggable supported"
